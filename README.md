# PlanBoard · 日计划看板

一个轻量、可定制的个人时间管理工具。界面是零依赖的原生 HTML/CSS/JS，装一层 Electron 外壳变成桌面应用——数据落在本机文件里，可备份、可手动查看。

![预览](https://img.shields.io/badge/状态-开发中-yellow)

## 功能

### 四个视图

- **周视图**（默认） — 一周七天并排的清醒日时间网格，任务块高度即真实时长，重叠任务自动分泳道并排显示；今天那一列有高亮底色和实时移动的当前时刻线
- **列表视图** — 一段起止区间内的日期纵向排成时间线，任务卡片可直接编辑；今日高亮，过去日期自动折叠
- **四象限** — 2×2 的优先级矩阵，四个格子一直画在那里，可以**直接点 + 自己填**，也可以把一堆待办丢给 AI 让它先分一遍再手动调
- **备忘录** — 左侧笔记列表 + 右侧编辑区（「+ 新建笔记」和「删除」在编辑区右上角），多条笔记按更新时间倒序，输入防抖自动保存

### 换周 / 换区间

- **周视图** — 一次一周，默认当前这一周
- **列表视图** — 一次一个**起止区间**，默认当前这一周（周一~周日），**最多 10 天**

| 控件 | 作用 |
|---|---|
| ← 上周 / 下周 → | 按 7 天平移，区间长度不变 |
| 回到本周 | 跳回当前这一周的周一~周日 |
| 起止日期选择器 | 直接选区间；起止倒置会自动交换，跨度超 10 天则以开始日期为锚截断 |

列表视图选中的区间记在本机（`pb_listRange`），下次打开还是它 —— 想回当前周点「回到本周」即可。

### 周视图

- **点空白时段** — 就地新建任务，弹窗里预填那一刻的起始时间和 1 小时时长
- **点任务块** — 打开编辑弹窗（内容 / 地点 / 分类 / 日期 / 起止 / 已完成 / 删除）
- **拖拽改时间** — 上下拖动任务块，按 5 分钟吸附
- **拖拽改时长** — 按住块底部边缘拖动，最短 15 分钟
- **跨天拖拽** — 水平拖到另一天，目标列高亮提示
- **课表模板** — 每周重复的课程/固定安排，以半透明虚线块叠加显示，统一用琥珀色（不受任务分类色影响）；**点它**只弹出**只读详情**（名称 / 地点 / 时间 / 日期 / 频次 / 生效范围），不给改、不给删、也不给「固化成任务」—— 课程的编辑入口只有课表日历一处，弹窗里两个动作之外就是「去课表日历改」
- **这天不上** — 只读详情里的按钮：课表本身不动，只把这一天的这个块盖掉（比如这节课调休不上）

### 课表日历

**📅 课表日历**（设置 → 学期与课表 → 打开课表日历）把整周铺成一张网格，改动**即时落盘**，不需要点保存：

- **点空格子** — 在那儿新建一门课（默认 90 分钟）
- **拖块身上下** — 改上课时间，按 15 分钟吸附
- **拖块身左右** — 换到另一天
- **拖块底边** — 改时长，最短 15 分钟
- **点块** — 右侧详情面板里改全部字段：名称 / 地点 / 周几 / 频次 / 起止 / 生效范围 / 持续周数 / 启用
- **悬停 ✕** — 删除

**课程不进「工作 / 学习 / 个人」那套分类** —— 那套是给任务的。课表里的课程统一用琥珀色（`store.js` 里的 `COURSE_COLOR`），和周视图里的任务色区分得开。

**生效范围可以从学期设置带出来。** 先在 ⚙ 设置 → 学期与课表 里填好**开学日期**和**学期结束日期**，之后新建课程时会自动把「生效起」填成开学日期、「生效止」填成学期结束日期 —— 不必每门课手打一遍，建完仍可单独改。

**持续周数**是「生效起 ↔ 生效止」的第三种写法，三者互推：

| 你改的 | 跟着变的 |
|---|---|
| 持续周数 = N | 生效止 = 生效起 + N×7 − 1 天 |
| 生效起 | 生效止按原周数一起平移 |
| 生效止 | 按整周对齐，再反算出持续周数 |

区间是**闭区间**（第 1 周 = 周一到周日，共 7 天），所以 2026-09-14 起 16 周正好止于 2027-01-03。只填「止」不填「起」也可以，此时只有上界生效。

时间窗口默认 **06:00–24:00**，有课程落在窗口外会自动撑开，保证不会有块因为看不见而「填错了都不知道」。单双周课程在块左上角标「单」/「双」，停用的课程半透明显示。

**单双周要靠开学日期算周次。** 没填开学日期时，单双周会**降级成每周**（`template.js` 的判定如此），详情面板里会有一条琥珀色提示把这件事说出来，而不是默默按每周排。

### 四象限

经典的艾森豪威尔矩阵，四个格子各有一个颜色：

| 格子 | 含义 | 颜色 |
|---|---|---|
| ① 重要且紧急 | 马上去做 | 红 |
| ② 重要不紧急 | 安排时间做 | 蓝 |
| ③ 紧急不重要 | 尽快清掉 | 琥珀 |
| ④ 不重要不紧急 | 有空再说 | 灰 |

**AI 是辅助，不是前提。** 两条路可以混着走：

- **自己填** — 点格子右上角的 `+`，就地写内容、选日期和时间
- **让 AI 分** — 把待办堆在上面的输入框里（一行一条）点「🤖 让 AI 分一下」，结果**补进**格子里，已经有的（手填的或上次分出来的）按文本去重跳过，不会覆盖你写的东西

每条都能**拖到别的象限**，理由、日期、时段都可改。确认无误点「✓ 确认写入」，条目才真正落进计划里（没填日期的落今天）。写入之后可以点「记住这次的偏好」，让 AI 把这次的判断依据总结成 1–3 条追加到 `preferences.md`——**不自动写**。

### 时间怎么填

周视图 / 列表视图 / 课表日历 / 任务编辑弹窗里的时间框都是**普通文本框，随便打**，回车或点到别处时补全：

| 你打的 | 变成 |
|---|---|
| `3` | `03:00` |
| `13` | `13:00` |
| `30` | 当前小时`:30`（两位且超过 23 就当分钟，不会把你的小时抹掉） |
| `330` | `03:30` |
| `1330` | `13:30` |
| `13:30` / `13.30` / `13 30` | `13:30` |

认不出来（比如 `abc`、`99`）就**保留原来的时间**，不会把已有值弄丢。框右边那个小钟点开还是系统自带的时间选择器，选完直接写回。

> 为什么不用原生 `<input type="time">`：它是「时 / 分」两格的分段控件，你打的数字一旦不可能再延长就**当场提交并跳走** —— 打 `3` 时 30–39 不是合法小时，所以立刻变成 `03`，光标也跑到下一格，没法连着打两位。

### 通用

- **自定义分类** — 添加/删除/改名/改色，按分类统计任务数量；改名是就地编辑，不弹原生对话框
- **学期日期即时保存** — 开学日期 / 学期结束日期一改就落盘，点 × 或点弹窗外关掉都不会丢
- **复选框追踪进度** — 实时统计完成率 + 进度条
- **内容直编** — 任务文本、分类、时间均可点击直接编辑
- **自动保存** — 所有变更自动写入存储
- **JSON 导出/导入** — 备份数据或迁移到其他设备
- **响应式布局** — 手机/平板/桌面均可使用
- **打印友好** — 打印时自动隐藏操作按钮
- **键盘快捷键** — `Ctrl+Enter` 确认 · `Esc` 取消 · `Ctrl+Esc` 开关设置

## 用法

### 下载安装包

到 [Releases](https://github.com/icy-soup/planboard/releases) 下载 `PlanBoard-Setup-2.0.0.exe`，双击按向导装。

安装包**没有代码签名证书**，Windows 大概会弹 SmartScreen 警告 —— 点「更多信息 → 仍要运行」即可。

装好后数据落在 `%APPDATA%\PlanBoard\data`，不是安装目录（安装目录写不进去）。

### 桌面版（推荐）

```bash
npm install                                   # 装 Electron
cscript //nologo tools\make-shortcut.vbs      # 生成 PlanBoard.lnk（在项目根目录）
```

然后双击 `PlanBoard.lnk` 启动。之所以用 `.lnk` 而不是 `.bat`：没有控制台黑窗，也绕开了 `.bat` 的中文编码问题。

也可以直接 `npm start`。**默认不自启、关窗即退出**；想要托盘常驻或开机自启，在 app 里 ⚙ 设置 → 桌面版 勾选。

### 浏览器版

用浏览器打开 `app/index.html` 就能用全部本地功能，数据存 `localStorage`。AI 调用需要跨域，浏览器下大概率不通——四象限会提示用桌面版。

### 上手

1. 点击 ⚙ 设置 → 设项目名称 + 自定义分类
2. 想用课表，先把「开学日期」（第一周周一）和「学期结束日期」填上 —— 它们决定单双周怎么算、新课程的生效范围默认填多少 —— 再点「📅 打开课表日历」把整周排一遍
3. 在周视图里拖拽安排时间，或切到列表视图按天添加任务
4. 用四象限把待办分个轻重缓急，写进计划
5. 可导出 JSON 备份，或导入恢复数据

## 关于「清醒日」

周视图的网格从 **05:00 起算，到次日 05:00 结束**，而不是 00:00–24:00。

这意味着**凌晨 0–5 点的任务归属于前一天**：例如周三 01:00 的任务，会显示在周二那一列的底部。这是为作息偏晚的人设计的——睡前做的那部分事情，在心理上属于「今天」而不是「明天」。

### 默认时间窗与折叠

整条轴上只有 **07:00 – 次日 01:00** 是默认露出的（每小时 48px），两端各折成一条窄带：

| 折叠带 | 收起 | 点开后 |
|---|---|---|
| 05:00–07:00 | 24px 窄条 | 96px |
| 01:00–05:00 | 24px 窄条 | 192px |

展开/收起的按钮在**左侧时间轴那一列**里，纵向对齐各自那条带子。按钮早先放在窄条上，会横跨到周日那一列压住任务，所以挪出来了 —— 收起时按钮显示「▸ 数量」（带子里藏了几项），完整说明在鼠标悬停提示里；展开时显示「▾」。展开状态记在本机（`pb_weekBands`）。完全落在折叠带内的任务不绘制，跨越边界的照常显示。

整块网格（时间轴 + 7 列 + 表头）还套了**自己的封闭内框**（`.week-frame`），内嵌在卡片里四周留白，滚到底也有余量。

### 时间轴换算

因为两端会被压扁，`offset → 像素` 不是简单乘法，而是一根**分段折线**：每段内部线性，段高按折叠状态取 24px 或「分钟数 × 48/60」。

换算函数集中在 `app/js/util.js`（`weekLayout` / `weekY` / `weekOffset`，以及基础的 `offsetFromTime` / `timeFromOffset` / `durationMinutes`），有单元测试覆盖跨午夜、跨折叠边界、四种折叠组合下的逆运算。

### 为什么 IPC 是同步的

`store.js` 的 `read()` / `write()` 都是同步调用（阶段一刻意如此，为的是浏览器与桌面共用同一份界面代码）。Electron 那侧若用 `ipcMain.handle` + `invoke` 就是异步的，会逼着所有视图改成 `async`。

所以存储通道用 `ipcMain.on` + `event.returnValue`，preload 用 `ipcRenderer.sendSync`——**接上文件后端时界面代码一行都不用改**。写一个几百 KB 的本地 JSON 文件是毫秒级的事，同步阻塞的代价可以忽略。

AI 和密钥那几条通道是异步的（`invoke` / `handle`），因为 `fetch` 本来就是异步的，而调用点（四象限按钮）也已经是 async。**同步/异步按调用方的形状选，不是按一致性好看来选。**

### 模块约定

所有 `app/js/*.js` 采用同一套模式，使同一份文件既能作为浏览器经典脚本运行，又能在 Node 下被 `require` 做单元测试：

```js
(function () {
  'use strict';
  const PB = (globalThis.PB = globalThis.PB || {});
  // ... 实现 ...
  PB.xxx = api;
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
})();
```

脚本加载顺序由依赖决定，不能乱：

`util` → `store` → `template` → `memory` → `ai` → `view-list` → `view-week` → `quadrant` → `memo` → `settings` → `tpl-cal` → `edit-modal` → `main`

刻意不使用 ES module，以保证 `file://` 下双击即可打开。

### HTML 转义有两个函数，别用混

- `util.escapeHtml(s)` — 走 `textContent` / `innerHTML`，挡 `&` `<` `>`，**不挡引号**。用于元素内容。
- `util.attr(s)` — 额外挡 `"`。**凡是拼进 `value=""` / `title=""` 这类属性值里的，必须用这个。**

用错的那个，用户输入里带一个双引号就能从属性里跑出来。

## 数据存储

### 桌面版 — 文件

| 路径 | 内容 |
|---|---|
| `data/planboard.json` | 全部状态（配置、任务、课表模板、备忘录） |
| `data/secrets.json` | DeepSeek API Key，与主数据分开，导出 JSON 不会带出去 |
| `data/memory/*.md` | 个人背景记忆，按主题分四份 |
| `data/backups/` | 自动备份快照 |

**备份**：每次写盘前看一眼 `backups/` 里最新一份的时间戳，距上次**超过 10 分钟**才再备一份（备的是覆盖前那一份），保留最近 **20** 份，超出的删最旧。备份失败只记 console，不阻断主写入。

**损坏恢复**：`planboard.json` 解析失败时，从 `backups/` 由新到旧找第一份还能解析的顶上，并 toast 告知；全都不可用才退回空数据。

**v1 迁移**：首次启动若 `data/planboard.json` 不存在，但浏览器里还留着 `pb_config` / `pb_tasks`，就把 v1 数据搬进来并 toast 提示。**原 localStorage 不删**，留作额外保险。

### 浏览器版 — localStorage

| 键 | 说明 |
|---|---|
| `pb_state` | 全部状态（v2） |
| `pb_activeView` | 上次停留的视图（`week` / `list` / `quadrant` / `memo`） |
| `pb_listRange` | 列表视图上次选中的起止区间 |
| `pb_weekBands` | 周视图两条折叠带的展开状态 |
| `pb_memory_*` | 记忆文件（桌面版下换成 `data/memory/`） |
| `pb_deepseekKey` | 浏览器版的 API Key（桌面版下密钥留在主进程） |
| `pb_config` / `pb_tasks` | v1 遗留键，首次加载会被读取并迁移，之后仅作保险保留 |

`migrate()` 是纯函数：只补缺失字段，不覆盖已有值，且不修改入参。首次加载会把迁移结果固化写入。

「重置所有数据」走的是 `store.clear()`，即**写一份默认状态回去**，而不是删文件——删掉的话下次启动会被当成首次启动，v1 迁移会把旧数据重新搬回来。

导出文件为标准 JSON，可自由备份或分享。

## AI（DeepSeek）

### 调用链

```
界面 (ai.js) → window.planboardAPI.ai.chat(messages)
             → ipcRenderer.invoke('ai:chat')
             → 主进程 ipcMain.handle('ai:chat')
             → fetch('https://api.deepseek.com/chat/completions')
```

走主进程有两个原因：Node 侧 `fetch` 不受 CORS 限制；**API Key 只存在于主进程读的 `data/secrets.json`，不进入渲染进程**。设置页拿到的只有「配没配 + 尾号」，改密钥只能整体覆盖。

浏览器模式下 `ai.js` 降级为直接 `fetch`（Key 存 localStorage）。这条路**可能因 DeepSeek 的 CORS 策略不通**，失败时提示用桌面版。

### 个人背景记忆

`data/memory/` 下按主题分四份，设置页每一份一个「发送给 AI」开关（存 `config.settings.ai.memoryEnabled`）：

| 文件 | 内容 |
|---|---|
| `profile.md` | 身份、作息、习惯、精力曲线 |
| `courses.md` | 本学期课表（文字描述） |
| `goals.md` | 当前目标与截止日期 |
| `preferences.md` | 偏好，含 AI 自动积累的部分 |

调用时把勾选且非空的文件按标题分节拼进 system prompt，一起发过去的还有今天已排的时段（让 AI 别把新任务排在已有安排上）。未启用的文件**不读取、不发送**——这是对「哪些私人内容会被发出去」的显式控制。

### 输出容错

要求模型输出纯 JSON，解析时兼容 `{"items":[...]}` 与裸数组两种形状，并逐字段校验（象限越界归 4、日期/时间不合法就换默认值）。解析不了就**原样展示 AI 的回复并明确说没有写入**，绝不猜。

## 技术栈

| 层 | 技术 |
|---|---|
| UI | 原生 HTML + CSS（无框架、无构建步骤） |
| 交互 | 原生 JavaScript（经典 `<script>`，非 ES module） |
| 外壳 | Electron（窗口 / 托盘 / 开机自启 / 无跨域的 AI 调用） |
| 存储 | 桌面版走文件（经 IPC），浏览器版走 localStorage —— 同一套 `store.js` 抽象层 |
| AI | DeepSeek（OpenAI 兼容协议，模型名可配） |
| 测试 | Node 内置 `node:test` |
| 图标 | Unicode/Emoji + 内嵌 base64 PNG（无图标库依赖） |

## 路线图

- **阶段一** — 本地功能：周视图 / 列表视图 / 备忘录 / 课表模板 / 课表日历 / 视图切换，纯浏览器可用
- **阶段二** — Electron 桌面化：窗口与同步 IPC、文件存储、备份轮转与损坏回退、v1 数据迁移、托盘与自启开关、`.lnk` 快捷方式
- **阶段三** — AI 辅助：DeepSeek 调用链、API Key 管理、个人背景记忆编辑器、四象限、偏好自动积累
