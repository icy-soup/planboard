# PlanBoard · 日计划看板

个人时间管理工具。界面是零依赖的原生 HTML/CSS/JS，套一层 Electron 当桌面应用，数据落在本机文件里 —— 可备份、可手动查看。

## 功能

**四个视图**

- **周视图**（默认）— 一周七天并排的时间网格，块高即真实时长，重叠任务自动分泳道；顶上单独一条带子放全天 / 跨天任务
- **列表视图** — 一段起止区间（最多 10 天）排成时间线，卡片上直接改时间 / 分类 / 文字
- **四象限** — 2×2 优先级矩阵，四个格子一直画着，点 `+` 自己填；也可以把待办丢给 AI 先分一遍 —— AI 结果只**追加**并按文本去重，**不覆盖**你写的东西
- **备忘录** — 左列表右编辑，防抖自动保存

**任务**

- **「全天」和「跨天」是两个独立维度。** `全天` = 不占时间格，画在顶部带子里；`跨天`（写一个晚于起始日的「持续到」）= 覆盖起始日到那天。只要其中一个、两个都要，都行
- 带时段又跨天的（比如连着 x 天的每天 22:15–22:55），会在**覆盖到的每一天**的时间网格里各画一块，虚线左边框表示它连着好几天
- 跨天时还能选**做完一次即可 / 每天都要做**，后者每天单独打勾
- 只占一天的全天任务可以拖到别的日子；**跨天的一律不给拖** —— 拖走一块该动的是范围，不是某一格
- 拖拽改时间 / 改时长（吸附 5 分钟），水平拖到别的列换天
- 时间框是普通文本框，随便打：`3`→`03:00`、`330`→`03:30`、`1330`→`13:30`、`13.30`→`13:30`；认不出来（`abc`、`99`）就保留原值，不会把已有时间弄丢
- **课表模板** — 每周重复的课程 / 固定安排以半透明虚线块叠加，统一琥珀色；编辑入口只有课表日历一处，周视图里点它只有只读详情

**通用** — 自定义分类（增删 / 改名 / 改色）· 完成率进度条 · 全自动保存 · 单实例锁 · 响应式 · 打印友好 · `Ctrl+Enter` 确认 / `Esc` 取消 / `Ctrl+Esc` 设置

### 清醒日

周视图从 **05:00 起到次日 05:00**，凌晨 0–5 点的任务归**前一天** —— 睡前做的事在心理上属于「今天」。

整条轴上只有 07:00–次日 01:00 是默认展开的（每小时 48px），两端各折成一条可点开的窄带。因为两端会被压扁，`offset → 像素` 不是简单乘法而是一根**分段折线**；换算集中在 `app/js/util.js`（`weekLayout` / `weekY` / `weekOffset` / `offsetFromTime` / `timeFromOffset`），有单测覆盖跨午夜与跨折叠边界的逆运算。

### 导入 / 导出

导出先选**日期范围**（默认取列表视图正在看的那一段，也可以勾「全部」），再勾要不要带上**课表模板 / 设置 / 备忘录**；任务只装区间内那几天，跨天任务只要有一段落在区间里就一起带上。

导入时选**合并**（同 id 的用文件里的覆盖）或**覆盖**（只换文件里出现过的那些日期，其余日期一条不动）。导入前先做形状体检，读不懂的文件直接拒收并说清原因，现有数据一点不动。

## 用法

**桌面版（推荐）**

```bash
npm install
npm start                                     # 或生成快捷方式，双击启动
cscript //nologo tools\make-shortcut.vbs      # → 项目根目录出现 PlanBoard.lnk
```

**浏览器版** — 直接用浏览器打开 `app/index.html`，本地功能全可用，数据走 localStorage；AI 调用需要跨域，浏览器下大概率不通，四象限会提示用桌面版。

**安装包** — 到 [Releases](https://github.com/icy-soup/planboard/releases) 下载 `PlanBoard-Setup-2.0.0.exe`。没有代码签名证书，Windows 大概会弹 SmartScreen 警告，点「更多信息 → 仍要运行」。

> **两套数据目录互不相通。** `npm start` / 桌面快捷方式（开发版）读写项目旁的 `data/`；装出来的那份读写 `%APPDATA%\planboard\data`。打开看到的是另一套数据，当前用的是哪个，⚙ 设置 → 桌面版 里有一行直接写出来。

**上手** — ⚙ 设置里设项目名和分类；想用课表就先把「开学日期」「学期结束日期」填上（决定单双周怎么算、新课程的生效范围默认填多少），再打开课表日历排一遍。

## 数据

| 路径 | 内容 |
|---|---|
| `data/planboard.json` | 全部状态：配置 / 任务 / 课表模板 / 备忘录 |
| `data/secrets.json` | DeepSeek API Key（与主数据分开，不在渲染进程里，导出也不带出去） |
| `data/memory/*.md` | 个人背景记忆：profile / courses / goals / preferences |
| `data/backups/` | 自动备份快照 |

写盘前看一眼最新那份备份的时间戳，**超过 10 分钟**才再备一份，保留最近 **20** 份；**导入 / 重置这类整批写入不受节流限制**，写盘前无条件先备一份。主文件解析失败时由新到旧找第一份还能解析的顶上。

**形状不对的内容不静默丢弃。** `tasks` 必须按日期分桶；是数组时按每条自带的 `date` 归位收编，实在读不懂的记进报告、界面 toast 说清原因并**这一次不回写盘**。（早期版本见到形状不对就静默换成 `{}`，把用户 9 条任务清空过。）

## 开发

```bash
npm test        # node:test，无依赖
npm run dist    # 打 Windows 安装包到 dist/
```

- **模块约定** — `app/js/*.js` 都是同一个 IIFE 模式：挂到 `PB.xxx`，同时 `module.exports`，于是同一份文件既能在浏览器里当经典脚本跑，又能在 Node 下 `require` 做单测。**刻意不用 ES module**，为的是 `file://` 下双击能打开。
- **脚本加载顺序不能乱** — `util` → `price` → `store` → `span` → `transfer` → `template` → `memory` → `ai` → `view-list` → `view-week` → `memo` → `quadrant` → `settings` → `tpl-cal` → `edit-modal` → `main`
- **HTML 转义有两个函数，别用混** — `util.escapeHtml` 走 `textContent`，用于元素内容（**不挡引号**）；凡拼进 `value=""` / `title=""` 这类属性值的**必须**用 `util.attr`。用错的那个，用户输入带一个双引号就能从属性里跑出来。
- **IPC 同步 / 异步按调用方形状选** — 存储走 `sendSync`（`store.js` 的读写本来就是同步的），AI 与密钥走 `invoke`（`fetch` 本来就是异步的），不是按一致性好看来选。
- 测试覆盖纯逻辑模块：清醒日换算、日期推算、数据迁移与形状收编、导入前体检、导出区间切片与按天覆盖合并、任务跨天搬运、课表模板判定与叠加、任务的跨天判定与两种完成方式、备份轮转与损坏回退、AI 返回解析、四象限条目流转。视图渲染与拖拽需手工验证。

## 技术栈

原生 HTML + CSS + JavaScript（无框架、无构建步骤）· Electron 外壳 · 桌面走文件 / 浏览器走 localStorage 的同一套 `store.js` 抽象层 · DeepSeek（OpenAI 兼容协议，模型名可配）· Node 内置 `node:test`
